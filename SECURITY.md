# Security policy

This project is intended for authorized local recovery of a computer you own or administer.

- Do not expose the device/API to the public Internet or configure port forwarding.
- Keep `private/`, flash dumps, provisioned firmware binaries, API tokens, Wi-Fi credentials and TLS private keys out of source control.
- Keep physical control of the ESP32, especially while keyboard input is armed.
- Report a suspected vulnerability privately to the repository maintainer before disclosing it publicly.
