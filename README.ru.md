# Arch S3 HID Recovery (RU)

Небольшой проект для восстановления собственного компьютера: ESP32-S3 определяется как USB-клавиатура, а управляется с Windows через HTTPS в локальной Wi-Fi сети.

Используйте только на своём устройстве или с разрешения владельца. ESP32 не видит экран ноутбука — оператор должен сам проверять меню загрузки и консоль. Этот способ не обходит шифрование диска: если система попросит ключ LUKS, нужен известный ключ.

## Нужно

- Плата ESP32-S3 с native USB (не только USB-UART); перед прошивкой проверить распиновку и размер flash.
- ESP-IDF 6.1.0, Windows PowerShell, Python 3.10+ и USB-кабель с передачей данных.
- Доступ обоих компьютеров к одной доверенной сети Wi-Fi 2.4 GHz.

## Сборка

В PowerShell ESP-IDF из корня проекта:

```powershell
python -m pip install -r requirements.txt
python .\provision.py --gui
.\build.ps1
```

В чистом проекте скрипт сам выбирает цель `esp32s3`. Если существующий `sdkconfig` настроен на другой чип, сборка остановится, не перезаписывая эту конфигурацию. Сначала сохраните файл и выберите ESP32-S3 явно.

SSID и пароль вводятся в локальное окно и сохраняются в `private/`. Там же создаются токен и TLS-сертификат. Не публикуйте эту папку, `firmware/build/`, дамп флеш-памяти или собранный firmware: в нём есть учётные данные и приватный TLS-ключ.

Перед прошивкой изучите текущую разметку платы и сохраните полный дамп локально. Не используйте erase. Скрипт прошивки требует локальный `private/esp32-original.bin` и реальные credentials; прошивка заменяет приложение и настроенную таблицу разделов. Применяйте только к плате, которую сможете восстановить из дампа.

## Запуск

Подключите ESP к Windows через native USB и прошейте. Затем перенесите кабель к ноутбуку, сохраняя питание, и выполните:

```powershell
python .\discover.py
python .\client.py --host DEVICE_IP status
python .\client.py --host DEVICE_IP interactive
```

Клавиатурный ввод разрешается отдельно командой `arm` и автоматически отключается через короткое время. После восстановления выполните `disarm` и отключите ESP. Новый пароль вводите локально на ноутбуке, никогда не отправляйте его по HID, в чат или аргументами команды.

Для стандартной Arch Linux без шифрования диска можно разово отредактировать запись GRUB и добавить `init=/bin/bash`, затем перемонтировать корень на запись и сменить пароль командой `passwd USERNAME`. Изменять сохранённый конфиг GRUB не нужно. Этот способ не поможет при неизвестном ключе LUKS, пароле загрузчика или неизменяемой подписанной загрузке.

## Ограничения безопасности

Сервер принимает только HTTPS; клиент проверяет отпечаток самоподписанного сертификата до отправки токена. Discovery по UDP не является аутентификацией. Любой человек с физическим доступом к включённой клавиатуре может вызвать нажатия — держите устройство под контролем и не открывайте порт в Интернет.
